# CLOX Script Compiler & Virtual Machine
A complete implementation of a compiler and virtual machine for the CLOX scripting language, built with C++ and ANTLR. This project transforms CLOX source code into an intermediate bytecode representation and executes it on a custom virtual machine.
## Overview
The project consists of two primary components:

    Compiler:
        Uses ANTLR to parse the CLOX language grammar.
        Performs lexical and syntactic analysis.
        Translates CLOX source code into bytecode.
    Virtual Machine:
        Executes the compiled bytecode.
        Implements a runtime environment for CLOX, handling operations, memory management, and error reporting.

This implementation aims to help me for building a solid foundation for understanding compiler design and virtual machine execution in a modern C++ environment.
